## 제작 기준

세 단 지형, 남북 레일 한 축, 북쪽 작업장과 남쪽 생활 구역을 유지한다. 돌과 놋쇠, 각진 지붕, 잿빛·황토색 표면에 화덕과 대장간의 주황빛을 집중한다. 메시는 큰 형태를 담당하고 표면의 판돌·슬레이트·나무결은 픽셀 텍스처로 표현한다.

Tripo는 `P2-20260801`, `quad=true`로 생성했다. 요청 수치는 최종 면 수 보증이 아니므로 Blender와 Unreal에서 실제 면 수를 기록한다. 파편 삭제와 열린 경계 보수는 원본 지문 검증 후 새 `.blend` 복사본에만 수행했다. 열린 시트에 일괄 노멀 재계산을 적용하지 않는다.

## 적용 내용

- 공용 6칸 이미지 아틀라스와 전용 재질 15종. 월드 좌표 투영으로 돌·흙·판돌·목재·지붕의 크기를 통일.
- 주거 건물 16채 교체, 주요 건물 지붕 6곳 교체. 고름의 집은 기존 검수본 유지.
- 암석·절벽 309곳과 소나무 95곳(기존 63 + 숲 가장자리 32) 교체. 원경 산줄기와 외곽 지형 보강.
- 길가 판돌, 작업장 적재물·차양, 문 옆 물건, 창빛, 계단 옆 벽 보강.
- 3대 광차 교체. 원본의 치우친 피벗은 메시 실측 최저점과 중심을 사용해 배치 보정.
- 화덕·대장간 픽셀 불꽃과 굴뚝의 상승 연기. 정적 교차 평면과 재질 애니메이션을 사용하며 Niagara 시스템은 아님.
- 하늘·안개 분리, 낮·밤 조명 조정. 신데하스 Director에서만 카메라 -25도 / 거리 2100cm / FOV 32 적용하며 레벨 종료 시 이전 카메라 값을 복원.

## 재실행과 보존

스크립트는 순서대로 1회 적용하는 편집 기록이다. 신규 자산·배치가 존재하면 중단하는 단계가 있으므로 전체 스크립트를 무조건 재실행하지 않는다. 원래 actor는 비활성 상태로 보존했으며 원본 자산은 유지한다. `assemble_level.py`를 다시 실행하면 이 수동 아트 패스가 초기화될 수 있다.

새 자연물을 교체할 때에는 이전 actor의 hidden 상태와 기존 통행로 개방을 함께 보존해야 한다. 공동묘지 접근로의 숨긴 절벽 네 곳을 다시 활성화하면 경로가 막힌다. 스크린샷의 R/B 채널 보정은 ScreenshotService의 저장 형식 보정이며 아트 리터치가 아니다. 카메라 이동 후 실제 프레임을 기다려 캡처해야 이전 뷰의 가림 판정이 남지 않는다.

최종 확인 결과는 `verification/` 및 `signoff.json`을 기준으로 한다. 그림의 외형 검수와 구조적 메시 검수는 별도로 기록하며 사용자 승인 전 이미지를 승인 기준선으로 등록하지 않는다.

## 검증

실제 PIE 이동: 레일 6/6, 공동묘지 4/4, 애쉬슬로프 10/10, 딥베인 6/6, 고름의 집 8/8, 파인할로우 5/5. Q0·Q7·Q8·Q9·Q11·Q12의 가림/충돌/군중 상태 검사와 Q12 컷신 이후 카메라·입력 복원, 장부고 출입을 확인했다. 카메라는 실제 PIE에서 -25도 / 2100cm / FOV32로 확인했다.

`verification/pine_player.png`는 실제 게임 카메라 HighResShot이다. `verification/final_viewport/`는 실제 레벨 뷰포트의 낮·밤 및 숲 정면·측면 검수다. `final/`과 `final_v2/`는 SceneCapture 조명/감마 차이와 교체 전 나무가 남은 진단 자료이므로 최종 화면으로 사용하지 않는다.

최종 진단 중 에디터 Renderer/D3D12 접근 위반이 두 번 발생했다. `UMaterialNodeService.cpp:67`의 `GetMaterialDiagnostics`는 조회 시 `ForceRecompileForRendering()`을 실행한다. 두 오류 모두 이 함수를 사용한 최종 검사 직후 발생해, 최종 재로드 검사에서는 해당 호출을 제거했다. 진단 도구 구현이나 엔진 자체를 수정한 것은 아니다. 로그는 `verification/editor_render_crash_0735.log`와 `editor_diagnostics_crash_0737.log`에 보존했다. 재시작 후 저장본 로드와 자산 검사 결과는 `verification/final_validation.json`, 추가 실행 확인은 `editor_stability.json`에 기록한다.
