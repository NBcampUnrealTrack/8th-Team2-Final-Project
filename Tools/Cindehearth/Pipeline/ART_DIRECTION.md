# 신데하스 환경 에셋 제작 기준

2026-09-05 사용자 확정: Tripo P2 스마트 메시의 네이티브 쿼드를 사용한다. 버텍스 디테일보다는 단순한 실루엣과 도트 텍스처로 완성도를 만든다.

- 생성: 공식 v3 `P2-20260801`, `quad=true`. H 시리즈의 `smart_low_poly` 옵션과 혼동하지 않는다.
- 고름 집 샘플: 목표 2,000 쿼드. 지붕 기울기, 처마의 큰 단차, 굴뚝, 출입구 윤곽을 우선한다. 개별 벽돌·못·균열을 작은 돌출 메시로 추가하지 않는다.
- 돌, 재, 그을음, 놋쇠 보수판, 낡은 도구는 텍스처의 큰 명암 덩어리로 읽힌다. 메시는 거주 3유형의 변주가 쉬워야 한다.
- Blender: 원본/작업본을 구분하고, 쿼드·UV·재질을 유지한 채 바닥 피벗과 게임 비례를 맞춘다. 무조건 정점을 합치거나 UV를 다시 펼치지 않는다.
- 교환: 편집용 `.blend`와 쿼드 보존용 FBX를 남긴다. Unreal 렌더 메시의 삼각화와 Blender 편집 토폴로지는 별도로 검증한다.
- Unreal: 원본 텍스처는 보존한다. 재질에서 UV 샘플 간격을 조절해 도트 밀도를 맞춘다. 낮은 노멀 강도와 높은 거칠기로 미세 광택이 캐릭터를 압도하지 않게 한다.
- 검수: 게임 카메라, 낮·밤, 고름 집 앞 출입 동선, Q12 에필로그 서신 프레임을 비교한다.
- Blender 정리 완료 조건: 연결된 면 묶음·열린 경계 검사 후 보이는 구멍과 떠 있는 조각을 선택 보수한다. 앞뒤 텍스처/무채색 렌더와 Unreal 화면을 함께 확인한다. loose vertex 0 또는 UV 검사 통과만으로 완료 판정하지 않는다. 열린 원본 판재의 면 방향을 일괄 재계산하지 않는다. 상세 기준은 [REPAIR_REPORT.md](REPAIR_REPORT.md).

H3.1로 먼저 생성한 `CH_GormHouse_Tripo_v001`은 비교용 원본이다. 최종 레벨에 사용하지 않는다.
