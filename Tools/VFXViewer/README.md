# 전투 VFX 뷰어

게임에 들어가 스킬을 쓰지 않고, 전투 무대에서 스킬 이펙트(Cast · Projectile · Impact)를 바로 확인하는 도구다.
- 언리얼 런타임으로 돌기 때문에 나이아가라는 실제 렌더 그대로다.
- 연출 규칙은 넷 전투와 같은 함수(`Battle/Presentation/NUBattleActionPresentation`)를 쓴다.
- 로그인 · 서버 · 필드 · 퀘스트는 건드리지 않는다.

## 띄우기

| 방법 | 언제 |
|---|---|
| `Scripts/run_vfx_viewer.bat` 더블클릭 (바탕화면 바로가기를 둬도 됨) | 에디터 없이 볼 때. 엔진만 `-game` 으로 뜬다 |
| 에디터에서 `/Game/Tools/VFXViewer/L_VFXViewer` 를 열고 Play | 에디터가 이미 켜져 있을 때. 저장 안 한 수정도 바로 보인다 |

- `-game` 은 에디터 DLL 을 쓴다. C++ 를 바꿨으면 먼저 `ProjectMEditor` Development 를 빌드한다.
  - 라이브 코딩 패치는 `-game` 에 안 들어간다.
- 첫 실행은 셰이더 · 나이아가라 준비로 느릴 수 있다.
- 창은 뜰 때 작업 영역 안으로 줄여 옮긴다(제목 표시줄 포함).
  - `-game` 은 DPI 를 모르는 프로세스라, 150% 배율에서는 요청 해상도가 작업 영역에 맞춰 줄면서 창 안쪽이 맨 위에 붙는다. 그래서 제목 표시줄이 화면 밖으로 나갔다.
  - 맞춘 결과는 로그 `LogNUVFXViewer` 의 "창을 작업 영역에 맞춤" 줄에 남는다. 사용자가 키운 창은 건드리지 않는다(시작할 때 한 번만).

## 화면

**왼쪽 패널** (Tab 으로 숨김) — 묶음 넷: 무대 · 전투원 / 재생할 연출 / 옵션 / 재생 결과
- **무대:** `/Game/Maps/BattleArena` 아래 레벨 전부를 검색 목록으로 고른다(목록에는 `L_Battle_` 를 뺀 이름, 마우스를 올리면 경로). 카메라 · 진형 · 조명이 게임과 같다.
  - 무대를 바꾸면 레벨을 다시 올리므로 방향키로는 안 바뀌고 클릭으로만 바뀐다.
- **시전자:** 캐릭터 · 아군 나이아 · 적.
- **성별:** 남캐 · 여캐. 명령줄은 `-Gender f`.
  - 누른 성별에 지금 직업 그림이 없으면 그 성별의 첫 직업으로 바뀐다(예: 남캐 나이아 나이트 → 여캐를 누르면 여캐 첫 직업).
- **직업:** 지금 성별에 전투 그림이 있는 직업만 버튼으로 나온다.
- **머리:** 패널 버튼은 없고 명령줄 `-Hair 4` 나 콘솔 `nu.VFX.Hair 4` 로 바꾼다(서버 hair_id 와 같은 값, 색까지 보려면 `4 + 색 번호 * 1000`). 0 이면 그 몸의 첫 머리.
  - 그 머리의 전투 그림이 없으면 몸 줄의 기본 전투 머리로 선다(`FNUBodyRow::CombatHairSkinsByPart`).
- **나이아:** 전투 그림이 있는 나이아만 나온다(`<` `>` 로 넘김). 적 수는 1~3 이다.
- **대상:** 아군이 시전하면 적 번호, 적이 시전하면 캐릭터 또는 나이아.
  - 스킬 표 모드에서 자신 · 아군에게 쓰는 스킬(`TargetPolicy` Self · SingleAlly · AllAllies)은 고른 대상 대신 그쪽으로 쏜다 — 자신은 시전자, 아군은 옆 전투원(없으면 시전자).
- **스킬 표 모드:** `DT_SkillVFX` 의 모든 행을 검색하고, 누르면 재생한다.
  - 오른쪽 분류: 직업 스킬은 직업 이름(직업 스킬 표의 `Class` = 직업 표의 `JobKey` → `DisplayName`), 그 밖에는 나이아 · 보스.
  - 검색은 번호 · 이름 · 직업 이름 · `Class` 값 · "직업" 어느 것으로도 된다. 시작할 때 분류별 개수가 로그 "스킬 목록" 줄에 남는다.
  - 맨 위 "기본 공격"은 캐릭터면 직업 기본 공격 연출(`JobAttackVFX`)로 바뀐다. 게임과 같다.
- **직접 지정 모드:** Cast · Proj · Impact 세 칸에 `/Game/VFX` 의 나이아가라를 골라 넣는다.
  - 목록에서 고른 뒤 그 칸의 [목록에서] 를 누른다.
  - 색은 속성 6색 · 흰색 · RGB 직접 입력. 이동은 제자리 · 중앙 · 대상, 타격 수도 정할 수 있다.
  - 스킬 표 모드의 [직접 지정 칸으로 복사] 로 스킬 하나를 옮긴 뒤, 한 칸만 바꿔 비교할 수 있다.
- **옵션:** 피격 이펙트 · 새로고침 · 패널 숨김.
- **재생 결과:** 최종 세 칸 · 색 · 반전 · 이동 · 시간표(예고 · 접근 · 행동 · 시전 · 타격 · 복귀)와 경고.
- 버튼에 마우스를 올리면 설명이 뜬다.

**진행바** (3D 화면 아래, 패널과 같이 Tab 으로 숨김)
- 버튼: 처음으로 · 0.1초 뒤로 · 한 프레임 뒤로 · 재생/일시정지 · 한 프레임 앞으로 · 0.1초 앞으로, 오른쪽에 속도 · 반복.
- 막대는 단계 구간으로 칠한다 — 예고 · 접근 · 행동 · 복귀 · 잔상(행동이 끝난 뒤 이펙트가 남은 시간). 지난 만큼 진하게 칠해진다.
  - 청록 눈금 = 시전(투사체 출발), 빨강 눈금 = 타격.
  - 잔상 길이는 한 번 끝까지 재생해야 안다. 처음 재생 동안은 막대가 늘어난다. 같은 연출이면 다시 틀어도 잰 길이를 쓴다.
  - 잔상이 "행동 끝 + 3초" 로 꽉 차면 그 이펙트에 끝나지 않는 이미터가 있다는 뜻이다(뷰어는 3초까지만 기다린다). 게임에서도 그만큼 보이지 않는 컴포넌트가 남는다.
    - 예: 10/14 `NS_Job_Cast_BuffGuard` · `BuffHaste` · `BuffMend` 의 `GroundRing` — 입자 하나가 실행 시 수명 100초 · 폭 0 으로 생겨 안 보이면서 시스템을 붙잡았다. 이미터를 껐다.
- 막대를 누르거나 끌면 그 시각으로 간다. 끄는 동안은 멈추고, 놓으면 끌기 전 상태(재생 · 일시정지)로 돌아간다.
- 시각 표시는 재생 시작 기준 초와 프레임 번호(1/60초)다.

**되감기는 이렇게 돈다** — 연출(아바타 이동 · 모션 · 투사체 · 피격 타이머 · 나이아가라)이 월드 시간으로만 흘러 거꾸로 돌릴 수 없다.
- 앞으로는 이어서 흘린다. 뒤로 가면 무대를 비우고(이펙트 · 투사체 · 피격 반응 · 모션 · 흔들림 · 암전) 처음부터 다시 흘린다.
  - 아바타를 제자리로 돌릴 때 액터 크기는 지킨다. 전투 도트 배율(`UNUFieldDotZoom`)이 깊이마다 넣은 크기라서다. 제자리(`HomeTransform`)는 크기 1 로 저장돼 있고 도트 배율은 월드가 흐를 때만 다시 넣는다.
- 흘릴 때는 1/60초 고정 간격이다. 자동 캡처와 같은 조건이라 정상 재생과 같은 화면이 나온다(같은 시각 캡처를 비교해 확인).
- 몇 프레임 넘게 감을 때는 직전 화면을 3D 칸에 덮어 두고 월드를 안 그린다. 그래서 빠르다(1/60초 한 칸에 약 1.5ms, 2초 되감기 약 0.2초).
  - PIE 에서는 덮개 없이 그리면서 감는다. 느리지만 깜빡이지 않는다.
- 나이아가라의 무작위 값(입자 방향 등)은 다시 흘릴 때마다 달라진다. 모양은 같고 입자 배치만 조금 다르다.

## 게임과 같게 맞춘 것 / 다를 수 있는 것

- **시간 기본값:** 넷 전투 프리셋(`NetAllyActionMotion` · `NetEnemyActionMotion`)이다. 로컬 전투는 예고 0.3초가 더 있다.
- **임팩트:** 투사체가 도착할 때만 뜬다. 투사체 칸이 비면 게임에서도 안 보인다.
  - 패널이 경고를 띄우고, [운반체 투사체 채우기] 로 `NS_Job_Proj_Carrier` 를 넣을 수 있다.
- **타격 수:** 스킬 표 값을 쓴다. 넷 전투는 서버가 보낸 타격 칸 수라 다를 수 있다.
- **피격 이펙트:** 첫 타격 시각부터 타격 간격마다 `GameplayCue.Battle.Hit` 로 낸다(끌 수 있음).
  - 피해량은 1 로 넘긴다(0 초과 판정용). 그래서 피해량에 따라 갈리는 연출이 있으면 다를 수 있다.
- **화면에서 빠진 것:** 피해 숫자 팝업 · 스킬 이름 배너 · 체력바는 안 나온다.

## 새로고침 (F5)

**`-game` 일 때**
- 에셋을 메모리에서 내린 뒤 디스크에서 다시 읽는다. 그러니 에디터에서 VFX 를 고쳐 **저장**한 다음 F5 를 누른다.
  - 다시 못 읽은 에셋은 패널에 개수가 뜨고, 무엇이 잡고 있는지 로그에 남는다. 그때는 뷰어를 다시 켠다.
- 뷰어는 `/Game/VFX` 패키지의 파일 핸들을 놓는다. 그래서 뷰어를 켠 채로 에디터에서 이펙트 · 머티리얼 · 텍스처를 저장할 수 있다.
  - 다른 폴더(무대 레벨, 캐릭터 그림 등)는 뷰어를 끄고 저장한다.
- 피격 이펙트(`NS_HitEffect`)는 큐 블루프린트가 붙잡고 있어 F5 로는 안 바뀐다. 뷰어를 다시 켠다.
- `DT_SkillVFX` · ini 변경은 뷰어를 다시 켜야 반영된다. 직접 지정 모드는 표와 무관하다.

**PIE 일 때:** 에디터 메모리의 현재 에셋으로 전투원만 다시 세운다.

## 자동 캡처 (창을 안 보고 확인)

```powershell
.\Scripts\run_vfx_viewer.ps1 -Skill 3010 -Caster player -Job 1001 -ShotAt 0.3,0.6,1.0 -Quit -Wait
.\Scripts\run_vfx_viewer.ps1 -Cast /Game/VFX/.../NS_A -Proj /Game/VFX/.../NS_B -Impact /Game/VFX/.../NS_C -Color "(R=5,G=0.5,B=0.3,A=1)" -ShotAt 1.0 -Quit -Wait
```

- **결과:** `Saved/VFXViewer/<시각>/shot_NN_<초>.png` 와 `report.json`(최종 스펙 · 시간표 · 경고).
  - 경로는 `-Out` 으로 바꾼다.
- **여러 스킬 한 번에:** `-Skills '3206:1003','2201:n1004','170101:e1701' -ShotAtHit -0.02,0.05,0.15` 처럼 `스킬:시전자` 목록과 첫 타격 기준 시각을 주면 스킬마다 예열 → 본 재생 → 찍기를 차례로 한다.
  - 첫 타격은 화면의 타격 모션 시각(`timeline.hitTimes[0]`)이다. 게임의 타격 처리 시각(`firstHit`, 피격 큐가 뜨는 때)과 어긋나면 경고 "타격 처리 … 어긋남" 이 붙는다(10/14 전에는 제자리 행동이 접근 시간 0.45초만큼 늦었다).
  - 시전자: 숫자 = 그 직업 캐릭터(남캐부터, 그 성별 그림이 없으면 다른 성별로. `1003f` · `1003m` 처럼 끝에 f · m 을 붙이면 그 성별부터), `n<번호>` = 그 아군 나이아, `e<번호>` = 그 적 나이아, 비우면 지금 설정. 전투 그림이 없는 나이아는 지금 나이아로 대신하고 로그에 남긴다.
  - 파일은 `q<순번>_s<스킬>_<번호>_hit<+초>.png`, 보고서는 `report.json` 의 `entries`. 격자로 보려면 `python Saved/VFXAudit/tools/qsheet.py <폴더> <출력.png>`.
  - 항목마다 점검 기록도 남는다: 시간표(`timeline`) · 뜬 이펙트(`effects` — 칸, 처음 · 마지막으로 보인 시각, 최대 입자 수, 처음 화면 위치와 그때 시전자 위치) · 끝 시각(`end`) · 잔상 대기 상한에 걸렸는지(`endedAtTailCap`)와 그때 남은 이미터(`lingering`).
- **시각 기준:** 재생 시작 기준 초다. 고정 60fps 로 돌고, 찍는 프레임에 잠깐 멈춰 정확히 그 시각을 남긴다.
- **진행 순서:** 한 번 예열 재생을 한 뒤 찍는다. 첫 장면이 셰이더 준비로 비는 것을 막기 위해서다.
- **옵션:**
  - `-ShotUI` 는 패널까지 찍는다.
  - `-ShotReload` 는 다 찍은 뒤 새로고침하고 한 번 더 찍는다(`reload_` 접두).
  - `-HidePanel` 은 대화형 실행에서 패널을 숨긴다.
  - `-Extra '-VFXSeekShots'` 는 재생 중 그 시각을 기다리지 않고 진행바처럼 감아서 찍는다(`seek_` 접두, `-ShotAt` 을 적은 순서 그대로라 `1.2,0.3` 처럼 주면 뒤로 감기를 확인한다). 감기 한 번마다 로그에 "감기 끝: 시각 (칸 수, 실제 ms)" 가 남는다.
- **그 밖의 인자:** `-Stage`(이름 일부) · `-Naia` · `-Enemy` · `-Enemies` · `-Target` · `-Motion inplace|center|target` · `-Hits` · `-NoHitCue` · `-Speed` · `-ResX/-ResY` · `-EnginePath` · `-Compare <후보.json>`(아래 "후보 비교").
- **준비 뒤 콘솔 명령 (`-Cmds`, 뷰어 인자 `-VFXCmds`):** 뷰어가 준비되면 1초 간격으로 `;` 로 나눈 콘솔 명령을 차례로 돌린다. `-Quit` 이면 다 돌고 DT 다시 채우기까지 끝난 뒤 종료한다.
  - 예: `.\Scripts\run_vfx_viewer.ps1 -Cmds 'nu.VFX.Variant 0 2;nu.VFX.Choose;nu.VFX.Apply yes' -Quit -Wait` — 기본 공격 두 번째 후보를 담아 적용. 결과는 `Saved/Logs/ProjectM.log` 의 `LogNUVFXViewer`.
  - `-ExecCmds` 는 무대 · 후보를 읽기 전에 돌아 후보 명령이 먹지 않는다.

**전체 점검 (`vfx_audit.py`)**

```powershell
python Tools/VFXViewer/vfx_audit.py                      # DT_SkillVFX 전체 + 기본 공격 (약 10분)
python Tools/VFXViewer/vfx_audit.py --skills 3206,2201   # 일부만 (0 = 기본 공격)
python Tools/VFXViewer/vfx_audit.py --report-only <폴더>  # 이미 돌린 결과로 보고서만 다시 (--keep-shots 로 돌렸을 때)
python Tools/VFXViewer/vfx_audit.py --stage Grassland01  # 무대 바꾸기
```

- 무대는 `--stage`(기본 Grassland04 — 정식 그림이 들어간 무대), 적은 1명 · 대상 0 으로 고정한다. 뷰어가 마지막 선택을 기억해서 안 고정하면 구도가 실행마다 달라진다. 적 화면 위치는 `audit.md` 머리에 적힌다.
- 시전자는 표에서 찾는다 — 직업 스킬은 `Class` → 직업 표 `JobKey`, 나이아 스킬은 `NaiaActiveLearnTable` 의 주인(전투 그림이 없으면 같은 속성 스타팅 나이아), 보스는 적 패턴 표.
- 결과 `Saved/VFXAudit/SkillAudit_<시각>/`: `audit.md`(문제 목록 · 항목별 · 점검 기준) · `audit.json` · `sheets/`(항목마다 타격 기준 4장, 12줄씩) · `report.json`. 원본 캡처는 격자를 만든 뒤 지운다(`--keep-shots` 로 남김).
- 판정 — **오류**: 끝나지 않는 이미터 · 에셋을 못 읽음 · 칸에 넣은 이펙트가 한 번도 안 보임. **주의**: 시전 · 임팩트가 예정 시각에서 0.05초 넘게 어긋남 · 시전자 · 대상에서 멀리 뜸 · 흰색 과다. **참고**: 긴 잔상 · 뷰어 경고 · 시전자 대체. 기준값은 스크립트 위쪽 상수.
- 숫자로 못 잡는 것(묻힘 · 높이 · 좌우 · 같은 속성끼리 구분)은 격자를 눈으로 본다 — `audit.md` 의 "AI 육안 검토" 칸.

**후보 비교 (`vfx_compare.py`) — AI 초안 → 뷰어 비교 → 사용자 선택**

AI(또는 사람)가 후보 파일에 후보를 적으면, 같은 스킬 · 같은 타격 기준 시각으로 나란히 찍고, 뷰어에서 그 스킬을 고르면 후보가 나와 번갈아 보며 고른다. 고른 것은 파일로 남아 다음 작업(표 연결 등)이 읽는다. 에셋 · 표는 바꾸지 않는다 — 후보는 스킬 표 행 위에 덮어 미리 볼 뿐이다.

- **후보 파일 자리:** 뷰어는 바로가기로 띄워도 아래를 모두 합쳐 읽고, 하나라도 생기거나 빠지거나 고쳐지면 1초 안에 다시 읽는다.

  | 자리 | 용도 | 커밋 |
  |---|---|---|
  | `Tools/VFXViewer/Candidates/*.json` | 팀이 같이 보는 후보. 작업마다 파일 하나(같은 파일을 여럿이 고치면 병합 충돌) | 함 |
  | `Saved/VFXViewer/Candidates.json` | 개인 실험. 아래 명령에서 파일을 안 주면 이 파일 | 안 함 |
  | `-Compare <파일>` · `open <파일>` | 그 밖의 파일. 그 파일의 첫 스킬로 바로 감 | - |

  - 후보가 가리키는 이펙트 에셋도 커밋돼 있어야 팀원 화면에 뜬다(없으면 "못 찾은 이름").
  - 고른 후보(적용 대기)는 사람마다 달라 개인 것이다: `Saved/VFXViewer/Pending.json`(아래 "적용 대기").

```powershell
python Tools/VFXViewer/vfx_compare.py new <후보.json> --skill 2001 --caster n1007 --slot impact --candidates NS_A,NS_B  # 한 칸만 바꾼 묶음 더하기
python Tools/VFXViewer/vfx_compare.py run <후보.json>       # 후보마다 찍어 Saved/VFXCompare/<이름>_<시각>/ 에 compare.md · sheets/set_NN.png
python Tools/VFXViewer/vfx_compare.py open [후보.json]     # 뷰어를 띄움 (파일을 주면 그 파일의 첫 스킬부터)
python Tools/VFXViewer/vfx_compare.py pending              # 적용 대기 보기
```

- 후보 파일 (예: `Tools/VFXViewer/compare_example.json` — 발현 3002 후보 5개(지금 · 이전 판 V2 · 충격파 · 묵직하게 · 금빛)와 땅 투사체 색 3개, 기존 에셋만 씀):

  ```json
  {"sets": [{"title": "땅 투사체 색", "skill": 2301, "caster": "n1013",
             "variants": [{"label": "지금"},
                          {"label": "갈색", "color": [1.5, 0.6, 0.15], "note": "채도를 낮춤"},
                          {"label": "구슬", "projectile": "NS_Job_Proj_OrbV3"}]}]}
  ```

  - 묶음(`sets`) 하나 = 스킬 하나의 후보들. 파일 정리 단위일 뿐 화면에는 안 보인다 — 같은 스킬이 여러 묶음에 있으면 후보를 모아 한 줄로 보여 준다.
  - `caster` 는 `-VFXSkills` 와 같은 표기(숫자 = 직업, `n<번호>` = 아군 나이아, `e<번호>` = 적 나이아, 비우면 지금 설정). 후보가 있는 스킬을 고르면 이 시전자로 바뀐다(후보끼리 같은 조건).
  - 칸 · 색을 하나도 안 덮는 후보("지금")는 표 그대로라 첫 칸 하나로 모인다. 없으면 뷰어가 "지금"을 붙인다.
  - 칸(`cast` · `projectile` · `impact`) 키가 없으면 스킬 표 그대로, `""` 이면 그 칸을 비운다. 값은 전체 경로(`/Game/VFX/...`)나 이름(`NS_X`, 뷰어가 시작할 때 훑은 `/Game/VFX` 목록에서 찾음 — 그 뒤에 만든 에셋은 전체 경로로).
  - `color` 는 `[R, G, B]`(HDR 값 그대로) 또는 `"(R=..,G=..,B=..,A=1)"`. 게임처럼 색 하나가 세 칸 모두에 들어간다.
  - 칸이나 색을 하나라도 덮으면 표 행처럼 취급해, 캐릭터 기본 공격이 직업 기본 공격 연출로 바뀌지 않는다.
    - 단 캐릭터 기본 공격(스킬 0) 후보는 그 직업의 기본 공격 연출(`JobAttackVFX`) 위에 덮는다 — 적용도 그 항목에 쓰기 때문.
- 뷰어 (`open`, 또는 `run_vfx_viewer.ps1 -Compare <후보.json>`): "재생할 연출"의 스킬 목록에서 한다.
  - 후보가 있는 스킬에는 "후보 N" 이 붙는다. 검색 줄 옆 "후보 있는 것만"을 켜면 그 스킬만 남는다.
  - 그 스킬을 고르면 목록 아래에 후보 줄이 나온다. 첫 칸 "지금"(표 그대로)부터 틀고, 다른 스킬로 갔다 오면 다시 "지금"부터다.
  - `[` `]` 후보, `Shift+[` `]` 후보가 있는 앞 · 다음 스킬(그 스킬에 담은 후보부터), Enter 적용 대기에 담기(아래). ↑ ↓ · PgUp PgDn 은 스킬 목록이 쓴다.
  - 후보 메모 끝에 그 후보가 온 파일 이름이 붙는다.
  - "번갈아 보기"는 재생이 끝날 때마다 다음 후보로 넘어간다.
  - 후보 파일이 바뀌면 1초 안에 다시 읽고 보던 후보를 다시 튼다 — 뷰어를 켜 둔 채 AI 가 후보를 더하거나 고칠 수 있다. 새로 저장한 에셋은 F5(새로고침)로 다시 읽는다.
  - 콘솔 `nu.VFX.Compare <파일>` · `nu.VFX.Variant [스킬] <후보>`(1 = 지금) · `nu.VFX.Choose`.
- **적용 대기:** 후보에서 Enter(적용 대기에 담기)를 누르면 바로 바뀌지 않고 "적용 대기" 카드에 담긴다. 3단계 [적용] 이 이 목록을 표에 쓴다.
  - 스킬마다 하나. 다시 담으면 바뀌고, "지금"(표 그대로)에서 Enter 는 그 스킬을 대기에서 뺀다. 담은 후보 버튼에는 ✓.
  - 카드에는 스킬마다 칸별 "지금 -> 바꿀 값"(Cast · Proj · Impact · 색)이 나온다. 지금 = 뷰어가 시작할 때 읽은 DT_SkillVFX.
  - 색 후보는 그 스킬만 고정색으로 바뀐다(속성색 행이면 속성색을 끔, 같은 속성의 다른 스킬은 그대로).
  - 알림: 표에 행이 없으면 "적용하면 새 행".
  - 기본 공격(0)은 DT 가 아니라 `Config/DefaultGame.ini` 의 `JobAttackVFX`(직업마다 한 항목)라, 담을 때 보던 캐릭터의 직업을 같이 남긴다. 캐릭터로 틀 때만 담긴다(나이아 · 적은 직업이 없음).
  - [보기] 그 스킬로 가서 담은 후보를 튼다, [빼기] · [모두 비우기].
  - 저장: `Saved/VFXViewer/Pending.json` — 덮을 값(`apply`)을 같이 남겨, 후보 파일이 빠지거나 바뀌어도 담은 그대로 적용한다(후보를 지금 읽었으면 그 값으로 새로 고침).
- **적용 (`[적용 (N건)]`):** 적용 대기를 원본 CSV 에 쓰고 DT_SkillVFX 를 다시 채운다. 누구나 해도 되게 백업 · 되돌리기가 있다.
  1. 확인 창 — 실제로 쓸 값(지금 CSV 행 · ini 항목 기준의 칸별 차이), 건너뛰는 것(CSV · ini 가 이미 같음, 직업을 모르는 기본 공격), DT 와 CSV 가 어긋났으면 그 알림.
  2. CSV 를 `Saved/VFXViewer/Backups/` 에 백업하고 바뀐 행의 VFX 칸만 고친다(다른 행 · BOM · 줄 끝 · 색 칸 모양 그대로, 표에 없는 스킬은 새 행 `Job_<번호>` · `Boss_<번호>` · `<번호>`).
     CSV 경로는 DT 가 기억하는 원본(`AssetImportData`, DT 폴더 기준 상대 경로)이라 팀원 PC 에서도 그 사람의 레포로 풀린다.
  3. 뷰어의 표를 바로 바꿔 "지금" 이 새 값이 된다. 적용한 스킬은 대기에서 빠진다.
  4. DT 다시 채우기 — 에디터가 꺼져 있으면 화면 없는 에디터로 커맨드렛 `ProjectMSkillVFXTable` 을 돌린다(10초 안팎, 로그 `Saved/VFXViewer/Reimport.log`).
     에디터가 켜져 있으면 CSV 만 고치고 안내 창을 띄운다 — 에디터가 같은 DT 를 들고 있어 뒤에서 저장하면 서로 덮어쓰기 때문. 에디터에서 DT_SkillVFX [다시 가져오기], 또는 에디터를 끄고 [DT 다시 채우기].
  5. 커밋은 `Scripts/Data/SkillVFXTable.csv` 와 `DT_SkillVFX.uasset` 을 같이 한다(CSV 가 원본, uasset 은 CSV 에서 다시 만든 것).
- **기본 공격 적용:** `DefaultGame.ini` 의 `JobAttackVFX=` 한 줄 안에서 그 직업 항목만 고친다(다른 줄 · 다른 직업 항목 · 줄 끝 · 인코딩 그대로, 항목은 빈 칸을 안 적는 기존 모양).
  - 백업은 `Saved/VFXViewer/Backups/DefaultGame_<시각>.ini`, 이력은 같은 `Apply_<시각>.json` 의 `jobAttack`(항목 글자 그대로라 되돌리면 바이트까지 같아짐).
  - DT 다시 채우기는 없다. 뷰어 안의 설정은 바로 바뀌지만, 게임 · 에디터는 켤 때 ini 를 읽으므로 켜져 있었으면 다시 켜야 보인다.
  - 커밋은 `Config/DefaultGame.ini`.
- **이력 · 되돌리기:** 적용마다 `Saved/VFXViewer/History/Apply_<시각>.json`(누가 · 언제 · 행마다 적용 전 · 뒤 값 · 백업 · 다시 채우기 결과).
  - `[마지막 적용 되돌리기]` 는 되돌리지 않은 마지막 적용을 그 전 값으로 돌린다(그 적용이 만든 행은 지움). 그 뒤에 다시 바뀐 행이 있으면 확인 창에 알리고, 되돌리기도 백업 · `Revert_<시각>.json` 으로 남긴다.
- **DT 와 CSV 어긋남:** 뷰어가 시작할 때 DT 가 기억하는 원본 MD5 와 지금 CSV 를 견준다. 다르면(받기만 하고 안 채움 · 손으로 고침 · 에디터가 켜져 있을 때 적용) 카드에 알리고 `[DT 다시 채우기]` 가 보인다.
- 콘솔 `nu.VFX.Apply [yes]` · `nu.VFX.Revert [yes]` · `nu.VFX.Reimport` — `yes` 는 확인 창 없이(내용은 로그), 사람이 확인한 뒤 스크립트 · AI 가 부를 때.
- 찍기 (`run`): 무대 · 적 1명 · 대상 0 을 고정하고(전체 점검과 같음) 타격 기준 -0.15 · +0.05 · +0.20 · +0.50초를 찍는다. 파일은 `q<순번>_s<스킬>_v<후보>_...`, `report.json` 항목에 `compareSet` · `variant` · `variantLabel` 이 붙는다. `compare.md` 에 후보마다 밝은 픽셀 최대(휘도 230 이상) · 끝 시각 · 뷰어 경고가 나온다.

**첫 사용 끊김 재기**
- `-Extra '-VFXHitchLog','-VFXNoPrepare','-VFXNoWarmUp'` 를 주면 게임의 첫 시전과 같은 조건(미리 불러오기 · 예열 없음)으로 첫 재생을 돌린다.
  - 40ms 넘는 프레임이 재생 시각과 함께 로그(`LogNUVFXViewer`)에 남는다.
- 여기에 `'-VFXAsyncPreload'` 를 더하면 게임의 전투 VFX 미리 불러오기(`UNUBattleVFXPreloadSubsystem`)를 거친 뒤에 잰다.
- 마지막 400ms 대 끊김은 스크린샷 저장이라 무시한다.

**콘솔 명령 (PIE · 콘솔 창)**

| 명령 | 동작 |
|---|---|
| `nu.VFX.Play [SkillId]` | 재생 |
| `nu.VFX.Speed <배속>` | 속도 |
| `nu.VFX.Seek <초>` | 그 시각으로 감기 (진행바와 같음) |
| `nu.VFX.Step [프레임]` | 프레임 넘기기, 음수면 뒤로 (기본 1) |
| `nu.VFX.Gender m\|f` | 성별 (패널의 성별 버튼과 같음) |
| `nu.VFX.Hair <번호>` | 머리 번호 (서버 hair_id 와 같음, 0 = 그 몸의 첫 머리) |
| `nu.VFX.Reload` | 새로고침 |
| `nu.VFX.Shot` | 지금 화면을 `Saved/VFXViewer/Manual` 에 저장 |
| `nu.VFX.Compare <파일>` | 후보 파일을 읽고 후보가 있는 첫 스킬을 틂 |
| `nu.VFX.Variant [스킬] <후보>` | 그 후보를 틂 (1 = 지금, 표 그대로) |
| `nu.VFX.Choose` | 지금 후보를 적용 대기에 담음 (`Saved/VFXViewer/Pending.json`) |
| `nu.VFX.Apply [yes]` | 적용 대기를 원본 CSV · DT 에 씀, `yes` 는 확인 창 없이 |
| `nu.VFX.Revert [yes]` | 마지막 적용 되돌리기 |
| `nu.VFX.Reimport` | 원본 CSV 로 DT_SkillVFX 다시 채우기 |

- `Tools/VFXViewer/vfx_audit.py`(전체 점검) · `vfx_compare.py`(후보 비교) · `compare_example.json`(후보 파일 예) · `Candidates/`(공용 후보).
- **감기의 시간 간격:** `FApp` 고정 시간 간격을 잠깐 빌린다.
  - UE 5.8 의 `FApp` 시간 값은 스레드별 시간 문맥(`FAppTime`)이다. 그래서 액터 틱(태스크) 안에서 바꾸면 태스크가 끝날 때 되돌아간다.
  - 감독은 틱에서 다음 간격만 정해 두고, `FCoreDelegates::OnBeginFrame`(엔진이 이번 프레임 시간을 정하기 전, 태스크 밖)에서 넣는다.
- **덮개 그림:** `UGameViewportClient::OnScreenshotCaptured` 에 묶은 채 3D 칸만 화면 캡처를 요청한다. 신호가 묶여 있으면 파일 대신 픽셀이 넘어온다.
- **전투원:** 넷 전투와 같은 아바타 클래스(`Net*AvatarClass`)를 쓰고, 같은 순서로 초기화한다.
  - 순서는 `SetServerAppearance` → `InitializeNetAvatar` → `SetIsAlly`.
- **재생:** `ResolveMotionTiming` → `MulticastPlayAction` 이다. 넷 액션 큐와 같다.
- `/Game/Tools/VFXViewer` 는 쿠킹하지 않는다(`DefaultGame.ini` `DirectoriesToNeverCook`).
