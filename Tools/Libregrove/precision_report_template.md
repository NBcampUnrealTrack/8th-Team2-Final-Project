# 리베르그로브 Blender 메시·UV 정리본 V2

2026-09-08 · Blender 5.0.0 · 사용자 승인으로 확장한 typed Blender MCP

## 결과와 사용 범위

9종의 크기 보정, 토폴로지 정리, 중복 면 제거, UV 펼침 및 GLB/FBX 왕복 검사를 마쳤다. 이전 PARTIAL 묶음 대신 이 폴더의 파일을 사용한다. **메시·UV 기술 검사는 통과했지만, 최종 게임 성능·아트 승인은 아니다.** 대부분의 건물과 나무는 초기 정점/삼각형 예산을 넘고, 일부 지붕·창틀·단상에는 원본 생성 형상의 거친 부분과 틈이 남아 있다.

원본 mAP.blend는 덮어쓰지 않았다. 작업은 원본 복제와 새 경로에서 진행했다. `Libregrove_GameMeshes_FINAL.blend`에는 채택한 9개 메시만 `LG_MODELS_V2` 컬렉션에 있다. 보기 편하도록 8m 간격으로 배치했으며 레벨 배치가 아니다. Blender에서 Home 키로 전체를 볼 수 있다. 개별 `models/` 파일은 원점·바닥 중앙 피벗 기준이다.

## 실제 치수와 정점 예산

치수는 **이 프로젝트의 게임 월드 cm**다. 기존 제작명세의 캐릭터 약 88cm, 설계 1m→45cm 기준을 유지했다. 현실 성인 사람 크기의 건축 실측 치수가 아니다. 높이를 기준으로 균등 리사이즈했으므로 가로·깊이는 원본 비례를 따르며 초기 명세값과 다르다. +X 정면, +Y 우측, +Z 위. Scale은 1이다. 문 개구부·플레이어 캡슐·실내 보행 치수는 검증하지 않았고, 건물은 외관용 모델이다.

초기 권장은 자동 생성 전의 **LOD0 목표**이지 플랫폼의 절대 한계가 아니다. 실제 삼각형이 초기 상한을 넘는 것은 {{OVER_BUDGET}}종이다. 형상이 망가지는 일괄 감량본은 채택하지 않았다. 다음 경량화는 기와·창틀의 수동 리토폴로지/노멀 베이크, 반복 부품 재사용, 거리별 LOD로 진행하는 것이 적절하다. 이는 이번에 수행한 작업은 아니다.

Blender 정점은 메시 데이터의 정점, GLB 렌더 정점은 UV·노멀 경계 분할까지 반영한 내보내기 수치다. 서로 다른 수치이며 실제 엔진 빌드 정점과도 반드시 같지 않다. 경계를 안전하게 분리하면서 Blender 정점이 증가한 모델이 있지만, 삼각형 수나 프레임 성능 증가와 동일한 뜻은 아니다. 노멀 분할·UV 단순화 효과는 GLB 수치에서 확인한다.

## 검증 결과

{{QA_TABLE}}

9종 모두 검사한 비정상 좌표/노멀, 고립 정점/에지, 0길이 에지, 퇴화 기하 면, 정확히 같은 위치의 중복 삼각형은 0이다. 표의 비다양체 에지는 **3개 이상 면이 공유하는 에지**를 뜻한다. 열린 경계는 별도다. 모든 경계가 의도된 것이라고 검증한 것은 아니며, 전체 밀폐(watertight) 메시가 아니다. 비정상 노멀 0 역시 모든 면이 바깥을 향한다는 증명은 아니다. 기존 양면 재질 조건을 유지했으므로 엔진에서 임의로 단면 재질로 바꾸면 일부 면의 가시성이 달라질 수 있다.

마지막 정리에서 좌표·재질이 일치하는 중복 삼각형 58개를 복제 작업본에서 제거했다. 반대 방향의 중복은 기존 양면 재질 조건을 확인한 뒤 정리했다. 원본 및 직전 단계 파일을 보존했으므로 복구할 수 있다.

UV_Game은 0–1 타일에 배치했다. 자동 투영은 60도 기준으로 나눈 뒤 면적을 맞추고 CONCAVE 방식으로 패킹했다. 겹침/퇴화가 확인된 삼각형만 별도로 재투영했다. 공방의 초박형 UV는 GLB의 float32 V 반전에서 정밀도를 잃어, 재패킹 없이 한 모서리 좌표를 최대 0.00001 UV 이내로 보정했다. 이 부분은 아주 작은 국소 UV 왜곡을 허용한 안전 보정이다.

UV 겹침은 삼각형을 2D polygon clipping으로 교차 검사했다. 절대 1e-11 / 상대 면적 1e-5 허용값과 퇴화 UV 면적 1e-12 기준이 있다. 공유 경계의 float32 오차를 제외하며 수학적인 무오차 증명은 아니다. 면적은 삼각형 면적 합계이며 텍셀 활용·베이크 품질의 최종 점수가 아니다. 패킹 간격 0.001 UV는 1024px에서 약 1px, 2048px에서 약 2px, 4096px에서 약 4px다. 작은 섬과 길쭉한 삼각형이 남으므로 실제 텍스처 해상도의 dilation/밉맵 번짐 및 체커 왜곡 검사는 별도다.

GLB는 파일의 POSITION/NORMAL/TEXCOORD_0/indices를 직접 읽어 치수·삼각형 수·UV 겹침/퇴화를 검사했다. FBX는 입력 해시를 고정하고 별도 Blender 프로세스에서 재임포트하여 동일 검사를 수행했다. 원본 Blender의 라이브 씬은 이 검사로 바뀌지 않았다. 9종 모두 양 형식에서 삼각형 수와 치수 일치를 확인했다.

## 대칭 검토

{{SYMMETRY_TABLE}}

근접률은 이전 원본의 반사 정점이 정규화 크기 약 1에서 0.01 거리 이내에 놓이는 비율이다. 원본 축을 기준으로 측정했으며 현재 +X 정면 좌표와 혼동하지 않는다. 완전한 표면 대칭률이나 정점 절감률이 아니다. 전체 강제 Mirror는 적용하지 않았다. 지붕 틀·기둥·문틀은 부분 대칭/반복 부품 후보지만, 기와·장식·문창 구성과 유기적 수목은 비대칭을 보존했다. Mirror는 편집과 UV 재사용에는 유리해도 내보낸 양쪽 삼각형을 자동으로 반으로 줄이지 않는다.

## 파일과 후속 작업

- `Libregrove_GameMeshes_FINAL.blend`: 채택 메시 9종만 담은 작업 파일.
- `models/`: 각 모델의 GLB·FBX 18개. 두 형식을 동시에 임포트할 필요는 없다.
- `views/`: 모델별 앞/뒤 사선 클레이 렌더 18개. 각각 독립 이미지다.
- `uv_layouts/`: 실제 최종 GLB UV 좌표를 그린 SVG 9개.
- `모델별_검수표.csv`, `manifest.json`: 초기 권장 정점, 실제 수치, 단위, 파일 해시.
- `qa/`: 최종 모델/GLB/FBX 검사 JSON, 테스트 및 조립 기록.

`blender-3d-modeling` 스킬의 typed-tool·원본 보존 규칙에 따라, 기능 공백은 사용자 승인 후 제한된 정밀 MCP 도구로 확장하고 합성 메시에서 시험했다. 임의 콘솔 입력 도구로 우회하지 않았다. 정밀 MCP 구현과 원시 단계별 증거는 프로젝트의 `Tools/Libregrove/` 및 `Docs/Libregrove/BlenderQA_20260908/evidence/`에 보존되어 있다.

충돌체, LOD, 라이트맵용 별도 UV, 노멀 베이크, 최종 텍스처/재질, Unreal 임포트·레벨 배치·쿠킹·실기기 프레임 측정은 하지 않았다. 따라서 파일명의 GAME은 에셋 용도를 나타낼 뿐, 최종 게임 배포 승인 표시가 아니다. 열린 경계/잔여 시각 결함 보수 및 목표 플랫폼 성능 검증이 필요한 정리본으로 전달한다.
