# 조절형 HD-2D 머티리얼 — 설계 기록

2026-09-09 구현·적용·기본값 복구 검수 완료. 아래는 초기 설계 기록이며, 실제 활성 에셋과 조절법은 [HD2D_CONTROLS.md](HD2D_CONTROLS.md)를 따른다.

2026-09-09 사용자 추가 요청: 파이널 판타지 레조넌스/옥토패스 참고의 도트 감성, 마스터 머티리얼 일괄 조절. Windows 우선, 추후 모바일 가능성 고려.

현재 엔진 UE 5.8.1 / Windows DX12 / Deferred. 원본 프로젝트 Lumen/VSM 설정은 변경하지 않고 V8 레벨의 기존 ScreenSpace GI/반사 설정을 유지한다. 원본 텍스처, V7 모델 기본 재질 및 기존 맵은 보존한다.

구성 계획:

- `M_LG8_HD2D_Surface`: 건물·나무·UV 기반 Tripo 소품. 원본 텍스처를 유지하며 UV에 고정된 픽셀 샘플링과 색상 스타일 적용.
- `MF_LG8_HD2D_Color`: 공통 색 단계·채도·명암·색조 함수.
- `MPC_LG8_HD2D`: 전체 강도, 픽셀 밀도, 색 단계, 포스터화 강도, 채도, 명암, 암부 보정, 거칠기, 노멀 강도, 발광 배율, 공통 색조.
- 지형·월드 정렬 소품·물·하늘은 용도별 마스터를 유지하면서 공통 색상 조절을 공유한다. 투명 물과 불투명 건물을 억지로 같은 렌더링 모드에 넣지 않는다.
- 개별 인스턴스에서 텍스처·픽셀 크기·재질별 강도 조절. 원본 스타일 복구 매핑과 기본 프리셋 보관.

화면 전체 저해상도 필터가 아니라 표면에 고정된 도트 표현을 사용해 UI와 캐릭터 윤곽을 보존한다. 모바일용 빛/반사/심도 비용과 실제 기기 검증은 별도이며, 현 단계에서 모바일 성능 인증을 의미하지 않는다.

완료 조건: 실제 레벨 적용, 원본 보존, 공통 파라미터 변경의 수치/화면 효과 확인, 기본 프리셋 복원 및 저장, 조절 설명서 제공.
