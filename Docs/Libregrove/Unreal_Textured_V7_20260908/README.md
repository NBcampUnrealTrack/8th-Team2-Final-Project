## 확인된 제한 및 다음 작업

- 원본에 경계 엣지·비다양체·퇴화 UV가 남아 있습니다. 숫자 검수는 임포트/크기/연결 확인의 통과이지, 토폴로지가 완벽하다는 뜻이 아닙니다. 상세 수치는 `model_audit.csv`와 `source_meshes.json`을 참조하세요.
- 실제 근접 화면에서 일부 지붕의 불규칙한 면·틈·거친 자기 그림자, 주택 뒤 벽의 흐릿한 문 모양 텍스처를 확인했습니다. 메시·UV·조명 각각의 기여를 완전히 분리 진단한 것은 아니며, 이 현상을 모두 해결했다고 주장하지 않습니다.
- 나이아 안식처 등 일부 뒷면은 앞면보다 텍스처 세부 묘사가 적습니다. 텍스처 누락과 별개인 외관 품질 검토 항목입니다.
- 현재 소스는 모델마다 합쳐진 정적 메시 1개입니다. 독립 문·힌지·애니메이션이 없어 **문 여닫기 기능은 들어 있지 않습니다**. V6의 문 애니메이션을 이 9종에 자동 이식하지 않았습니다.
- 충돌체 생성, LOD, 라이트맵 UV, 물레 회전·나무 바람, 캐릭터 이동/상호작용, 성능 측정·쿠킹은 미작업입니다. 검수 액터는 `NoCollision`이며 게임 플레이용 블루프린트가 아닙니다.
- 성역의 수정은 원본 Base Color 기반 불투명 재질입니다. 발광·반투명·이펙트 작업은 별도입니다.
- 원래 마을의 지형·길·강·배치·2.5D 카메라/조명 연출은 이 검수 레벨에 포함하지 않았습니다.
