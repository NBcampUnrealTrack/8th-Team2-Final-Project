추천과 다음 단계

1번 글래스 시트로 가고, 고를 것이 늘면 2번의 탭 구조로 넘어가는 순서를 권합니다. 지금 열린 선택은 성별·헤어 2·외모 1·이름뿐이라 탭으로 나누면 오히려 번거롭습니다. 3번의 등록증은 화면 전체로 쓰기보다, 생성하기를 누른 뒤 확인 창으로 쓰면 1번과 함께 갈 수 있습니다.

  1. 글꼴 결정 — 위의 ‘작은 글자’ 전환으로 비교해 보세요. 고딕을 섞으면 더 요즘 화면처럼 보이지만 프로젝트에 고딕 글꼴 에셋이 없어 한 벌을 새로 넣어야 합니다(목업의 고딕은 Noto Sans KR). 명조만 쓰면 추가 작업이 없습니다.
  2. 이 화면용 버튼 — 고르면 아이보리로 채워지고 글자가 남색으로 바뀌는 알약 버튼은 공용 버튼과 같은 C++ 부모를 쓰는 새 WBP로 만듭니다. 공용 버튼은 건드리지 않습니다.
  3. 무대와 함께 진행 — 지난번 순서(여관 정면 가져오기 → 레벨 재배치 → 열린 종족을 고른 채 시작하는 C++ 한 줄)는 그대로이고, WBP 단계만 고른 시안으로 바뀝니다.

네 장 모두 이 페이지에서 그린 목업입니다. 반투명 흐림, 밤 색감, 등불 번짐은 엔진에서 다시 맞춰야 하고, 실제 글자 크기와 여백은 WBP에서 한 번 더 조정이 필요합니다. 잠긴 종족의 ‘(준비 중)’ 글자는 지금 C++가 넣는 문구 그대로 두었고, 1번은 문양만 보이는 버튼으로 바꿔 자물쇠로 표시했습니다. 에셋과 코드는 건드리지 않았습니다.
