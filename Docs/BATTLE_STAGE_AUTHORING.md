# 전투 배경 세트 만들기

전투는 필드가 아니라 **땅 아래 아레나**(`ANUGameMode::ArenaCenter`, 기본 `0,0,-10000`)에서 벌어지고,
배경은 지역·심볼마다 지정한 **서브레벨을 동적으로 로딩**해서 그 위에 올린다. 이 문서는 그 서브레벨
하나를 만들 때 해야 할 것과, **어기면 조용히 틀리는 것**을 적어둔다.

기존 세트: `Content/Maps/BattleArena/L_Battle_Grassland01`(낮) · `L_Battle_Grassland02`(밤)

## 알아둘 전제 세 가지

| | |
|---|---|
| **캐릭터는 조명을 받지 않는다** | 스프라이트가 마스크드 **언릿**이다. 빌보드는 노멀이 수평이라 태양이 낮으면 밝기가 각도에 과민하고, 좌우 반전이 뒷면을 보여 적만 어두워졌다. 그래서 **조명은 배경만 담당**하고 캐릭터 명암은 아트에 그려져 있다 |
| **세트 조명은 전투 중에만 켜진다** | 세트 레벨은 전투가 끝나도 내려가지 않는다(같은 세트 재진입을 빠르게 하려고). 그래서 코드가 세트의 방향광·SkyLight 를 전투에 맞춰 켜고 끈다. **에디터에서 레벨을 열면 켜져 있는 게 정상** |
| **아무것도 놓지 않으면 기존 값으로 폴백한다** | 진형·카메라·조명 모두. 그래서 세트를 하나씩 옮겨갈 수 있다 |

---

## 1. 빈 레벨에서 시작한다

**필드 레벨을 복사하지 말 것.** `PlayerStart` · `BP_NUEncounterZone` · `AFieldEnemy` ·
`NavMeshBounds` 가 딸려와서 아레나에서 인카운터가 다시 터지거나 스폰 지점이 겹친다.
필요한 스태틱 메시만 가져온다.

액터는 **원점 주변에 배치**한다. 레벨 인스턴스가 아레나 좌표로 오프셋되어 로딩된다.

## 2. 진형

> ⚠ **이 절의 좌우 규약은 확정이 아니다.** 2026-08-21 회의에서 *Threads of Time* 방식
> (아군은 카메라 가까이 등을 보이고, 적은 멀리서 정면을 보는 **깊이 기반** 배치)이 논의됐다.
>
> 배치 자체는 **지금 코드로 이미 된다** — 축의 자리는 `GetActorForwardVector()` 기준이라
> 축을 돌리면 위아래·깊이·사선 전부 표현된다. 막고 있는 것은 **아트**다: 나이아·적 애님 BP에
> `SetDirectionality` 가 없어서 방향 입력이 조용히 무시되고, 아트 기준이 왼쪽 한 방향뿐이라
> 등 뷰·정면 뷰 스프라이트가 없다. 코드 쪽은 `GetActionLocation` 의 전진 부호가 두 진영이
> `Y` 로 갈린다고 가정하는 한 곳만 고치면 된다.
>
> **세트를 여러 개 만들기 전에 이 규약이 확정됐는지 확인할 것.**

좌우 배치만 쓴다. **아군은 인카운터 로컬 `+Y`(화면 오른쪽), 적은 `−Y`(화면 왼쪽).**

열은 세 개다 — `Player` / `Naia` / `Enemy`. 열마다 두 방식 중 하나를 고른다.

| 액터 | 방식 | 프로퍼티 |
|---|---|---|
| `ANUBattleFormationAxis` | 인원수만큼 축 Forward 로 **가운데 정렬** | `Row`, `SlotSpacing`(기본 150), `PreviewSlotCount` |
| `ANUBattleFormationSlot` | **손배치** 고정 자리 (보스 + 잡몹 구도) | `Row`, `SlotIndex` |

우선순위는 **슬롯 > 축 > 코드 상수**. 축에는 에디터 뷰포트에 미리보기 구가 그려지니
`PreviewSlotCount` 를 1·2·4 로 바꿔 보면서 자리를 확인한다.

- **`SlotIndex` 를 반드시 채운다.** 액터 순회 순서는 보장되지 않아서, 비우면 실행마다 보스와
  잡몹의 자리가 섞이고 재현이 늦다
- **슬롯이 인원보다 적으면 그 열 전체가 폴백된다** (Error 로그). 일부만 슬롯을 쓰면 아바타가 겹친다

## 3. 카메라

`ACameraActor` 하나를 놓는다. 세트 레벨에서 **먼저 찾은 하나**를 쓴다.

- **FOV** — `ACameraActor` 기본값은 90 이고 인카운터 카메라는 45 다. 기존 구도에 맞추려면 45 부근에서 시작
- **Yaw 를 크게 돌리지 말 것.** `+Y` 가 화면 오른쪽으로 읽히는 범위를 벗어나면 아군이 적을 등진다
  (좌우 반전이 하드코딩이다). 거리·높이·FOV·약간의 Yaw 까지가 바꿀 수 있는 범위
- 16:9 고정(`bConstrainAspectRatio`)은 코드가 꺼주므로 체크를 신경 쓰지 않아도 된다

## 4. 조명

| 요소 | 어떻게 | 왜 |
|---|---|---|
| **DirectionalLight** | 넣으면 전투 중 **필드 해가 꺼진다.** `ForwardShadingPriority = 1` 로 둘 것 (Light → Advanced) | 방향광은 스택이 아니라 **가산**이라 두 개면 과노출. 우선순위를 주면 에디터 경고가 사라지고 선택이 결정적이 된다 |
| **SkyLight** | `Source Type` 을 **Specified Cubemap** 으로 | 기본값 `Captured Scene` 은 **스카이박스 메시를 캡처해서** 아레나 전체를 하얗게 띄운다. 밝아지는 원인 1순위 |
| Point / Spot / Rect | 자유 | 반경이 있어 아레나 밖에 안 닿는다 |
| 노을 느낌 | **각도가 아니라 색으로.** Temperature 2500~3500K 또는 주황 Light Color + 후처리 그레이딩 | Pitch −10 이면 그림자가 높이의 **5.7배**로 늘어난다. −35~−45 면 1.0~1.4배 |

**세트 조명의 Visible 체크를 끄지 말 것.** 코드가 "배치되어 있는가"로 판단하므로 Visible 을 끈
조명도 전투 중에 켜진다. 안 쓸 거면 **삭제**한다.

필드 SkyLight 는 코드가 건드리지 않는다 — 나중에 등록된 것이 이겨서 세트 것이 알아서 위로 올라간다.

### 안개

**필드 안개는 전투 중에 무조건 꺼진다.** 조명과 달리 "세트에 없으면 필드 것을 쓴다"가 성립하지
않는다 — 아레나가 지면보다 10000 아래라 높이 안개의 밀도가 포화돼 세트가 통째로 뿌옇게 덮인다.
(증상 확인: 콘솔에 `showflag.Fog 0` 을 쳐서 그 뿌연 느낌만 사라지면 이것이다.)

세트가 자기 `ExponentialHeightFog` 를 들고 있으면 그것이 전투 중에만 켜진다. 조명과 같은 규칙이다 —
Visible 체크를 끄지 말고, 안 쓸 거면 삭제한다. **세트에 둘 이상 놓으면 하나만 적용된다** (Warning 로그).
국지 안개는 `ALocalFogVolume` 을 그대로 쓸 수 있다.

## 5. 하늘 — 스카이박스 메시

`SkyAtmosphere` 를 쓰지 않는다. 아레나가 지면 아래라 대기 모델이 의미를 잃고, 월드에 하나만
존재할 수 있어 필드 것과 충돌한다. **텍스처를 입힌 메시**로 만든다 (`M_Sky_Blue` · `M_Sky_Night01` 참고).

아레나와 **카메라를 함께 감싸는** 크기로 두고, 컴포넌트 플래그를 다음처럼 맞춘다.

| 플래그 | 값 |
|---|---|
| 머티리얼 | **Unlit** |
| Cast Shadow | **끄기** |
| **Affect Dynamic Indirect Lighting** | **끄기** ★ |
| Visible in Ray Tracing | 끄기 |
| Visible in Real-Time Sky Captures | 끄기 |
| Collision | No Collision |

★ **가장 안 찾아지는 함정.** 프로젝트가 Lumen GI 라서, 아레나를 감싸는 거대한 밝은 언릿 구는
**면광원처럼 작동해 아레나 전체를 띄운다.** 어둡게 만들려는 세트가 조명을 아무리 낮춰도
어두워지지 않고, 조명 설정만 쳐다보면 원인을 찾을 수 없다.

## 6. 빛줄기 (선택)

엔진 `LightShaftBloom` 은 쓸 수 없다 — 방향광만 되고, **태양이 카메라 앞에 있어야** 하며,
태양 위치에서 방사되는 화면 공간 효과라 카메라가 돌면 빛줄기가 따라 움직인다.
볼류메트릭 포그는 렌더러가 **첫 안개에서만** 읽는데, 전투 중에는 필드 안개가 꺼져 세트 안개가
그 자리를 가져간다 — 즉 세트 안개에서 켤 수 있다. 다만 비용이 크고 언릿 스프라이트에는 안 걸린다.

그래서 **메시 카드**로 만든다. 전투 카메라가 세트마다 고정이라 손배치가 항상 맞는다.

- 메시: 원뿔 (`/Engine/BasicShapes/Cone`). 좁은 쪽이 위 = 캐노피 틈에서 퍼져 내려오는 모양
- 머티리얼: `M_LightShaft` 기반 머티리얼 인스턴스 (`MI_LightShaft_Grassland01` 참고)
  - `ShaftColor` · `Intensity` · `EdgeFalloff` · `GroundFade`
  - `Intensity` 를 **1.0 이하로** 유지하면 후처리 블룸에 걸리지 않아 발광하지 않는다
- **회전** — 태양과 평행해야 한다: **`Pitch = 90 + 태양Pitch`, `Yaw = 태양Yaw`, `Roll = 0`**
  (검산: 태양이 수직 `−90` 이면 카드는 `Pitch 0` = 똑바로 선다)
- 플래그는 **5절의 스카이박스와 동일**. 특히 `Affect Dynamic Indirect Lighting` 을 꺼야 한다
- 3~6장, 폭·길이·세기를 다르게. 전부 같으면 인공적으로 보인다

## 7. 후처리 — Bounded PostProcessVolume

세트 분위기의 본체다. 코드가 필요 없고, 화면 전체에 걸리므로 **캐릭터도 같이 물든다.**

| | |
|---|---|
| **Infinite Extent 끄기** | 켜두면 전투가 끝난 뒤에도 필드에 남는다 |
| **볼륨이 카메라를 포함해야 한다** | 액터가 아니라 **뷰 위치**로 판정한다. 아바타만 감싸면 안 먹는다 |
| **Bloom → Threshold = 1.0** | 엔진 기본값이 `−1`(모든 픽셀이 블룸)이라 언릿 스프라이트가 번진다. 1.0 으로 올리면 LDR 스프라이트가 블룸에서 빠지고 실제 HDR 광원만 번진다 |
| Color Grading · DOF | 배경을 뒤로 밀어 캐릭터를 또렷하게 만드는 수단. 캐릭터를 밝게 올리는 방향으로는 발광에서 벗어날 수 없다 |

## 8. 등록과 배선

1. **`MapsToCook` 에 추가** — Project Settings → Packaging → *List of Maps to Include in a
   Packaged Build*. **맵은 소프트 참조로 쿡되지 않는다.** 빠뜨리면 에디터에서는 되고
   **패키징 빌드에서만** 배경이 사라진다
2. 세트를 쓰게 할 곳에 지정
   - 지역 단위: `BP_NUEncounterZone` 의 `BattleStageLevel`
   - 보스·심볼 단위: `AFieldEnemy` 의 `BattleStageLevel` (존과 별개로 자기 것을 든다)
   - 비워두면 이전 세트를 그대로 쓴다

## 절대 넣지 말 것

세트를 올릴 때 코드가 훑어서 **Warning 로그**를 남긴다. 막지는 않으니 로그를 확인할 것.

| 액터 | 왜 |
|---|---|
| `SkyAtmosphere` | 월드에 하나만. 아레나 깊이에서 대기 모델이 무의미하다. 5절의 스카이박스 메시로 |
| Infinite Extent `PostProcessVolume` | 전투가 끝난 뒤에도 필드에 남는다 |
| `VolumetricCloud` | 같은 이유. 고도 기반이라 아레나에서 의미가 없다 |

## 완성 검사

| | 확인 | 기대 |
|---|---|---|
| 1 | 세트로 전투 진입 | 세트 조명만. 로그에 `끈 필드 방향광=1개` |
| 2 | 전투 종료 → 필드 | **필드가 원래 밝기로 복귀** |
| 3 | 같은 세트로 재진입 | 세트 조명이 다시 켜짐 (레벨은 안 내려갔다) |
| 4 | 다른 세트와 왕복 | 각각 자기 조명. 조명 없는 세트에서 필드 해가 살아남 |
| 5 | **전투 종료 후 5초 안에** 다른 세트로 재진입 | 중간에 갑자기 밝아지지 않음 |
| 6 | 전투 화면이 뿌옇지 않은가 | 필드 안개가 꺼진다. 로그에 `끈 필드 ... 안개=1개` |
| 7 | 조명을 아주 낮춤 | 어두워진다. 안 어두워지면 스카이박스의 Lumen 기여(5절 ★) |
| 8 | 아군·적 밝기 | 같다 |
| 9 | 로그 | `스프라이트 머티리얼을 찾을 수 없습니다` · 금지 액터 경고가 없다 |
| 10 | 진형 | 인원수를 1·2·4 로 바꿔도 겹치지 않는다 |
| 11 | 패키징 빌드 | 배경이 보인다 (`MapsToCook`) |
