# 효과음 원본의 출처와 라이선스

효과음은 세 가지 원본으로 만든다. 원본 파일은 `Saved/SFX/`에만 두고(git 제외) 가공한 결과만 uasset으로 올린다.

| 원본 | 어디에 | 조건 |
| --- | --- | --- |
| ElevenLabs 효과음 API | `sfx_palette.json`의 prompt 줄 (후보 A~E) | 무료 요금제는 비상업(개인) 용도만 --- 상업 출시 전에 유료 요금제로 다시 받거나 다른 원본으로 바꿀 것 |
| 계산으로 만든 소리 | `synth_sfx.py` => `Saved/SFX/synth/` | 우리가 만든 것, 조건 없음 |
| 무료 실녹음 (아래 표) | `sfx_palette.json`의 src·extra 줄 => `Saved/SFX/free/` | 전부 CC0 (상업 사용 가능, 표기 의무 없음) |
