# 2페이즈 이끼나무 보스: 공격 VFX 4종 (HD-2D / 시간의 실타래 전투 뷰)

**전투 뷰:** 시간의 실타래처럼 카메라가 파티 어깨너머로 보스를 봅니다. **보스는 화면 안쪽(위쪽 가운데), 파티는 전경(아래)**에 서고, 공격은 화면 안쪽에서 카메라 쪽으로 다가옵니다.
**기준:** 1920×1080 화면. 플레이어 스프라이트(94px)를 2.5배, 보스를 native 260px의 2배(520px)로 놓고 맞췄습니다.

## 구성
| 종류 | 파일 | 머티리얼 / 필터 |
|---|---|---|
| 발광 플립북 | `*_Glow`, Telegraph, Swing, Hit, ParryCue, Charge, Push | Unlit Additive, `Emissive = RGB × A × 1.0~2.0`, Bilinear |
| 반투명 플립북 | `*_Dust`, `*_Leaves` | Unlit Translucent, `Emissive = RGB`, `Opacity = A`, Bilinear |
| **잔해 아틀라스 (픽셀)** | `T_Boss2_DebrisAtlas.png` + `.json` | Masked(0.5), **Filter Nearest**, NoMipmaps. 보스와 같은 2배 픽셀 밀도로 표시합니다. |

## 잔해(흙덩이·파편)
- 보스 원화의 색(나무껍질 갈색, 이끼 올리브, 외곽선 색)과 그리는 방식을 그대로 따랐습니다. 외곽선이 있는 껍질 판, 셀 셰이딩된 이끼 덩이, 흰 꽃, 늘어진 뿌리가 들어갑니다. 그다음 **보스 스프라이트와 똑같이 픽셀화**했습니다(같은 축소 방식, 같은 팔레트).
- 아틀라스는 4×4칸(칸당 144px)입니다. 0~3번은 언덕 덩어리(큰 것부터), 4~15번은 파편(큰 것부터)이고, 칸마다 실제 영역이 json의 `cells`에 있습니다.
- **플립북에 굽지 않고 파티클로 쓰도록 분리했습니다.** 낙하, 착지 순간의 파쇄, 튕김, 정지 후 사라짐까지 엔진에서 물리로 처리하는 편이 자연스럽고, 픽셀 선명도도 유지됩니다.

**Niagara 레시피 (언덕 무너뜨리기)**
1. 덩어리 이미터: 아틀라스 0~3번을 각각 1개씩 스폰합니다. 착지 프레임은 `fx.py`의 `HILL_SPEC`을 따르고(24fps 기준, 메인은 7프레임), 중력은 약 2600px/s²입니다. 낙하 중에는 위쪽에 속도선 스프라이트를 3줄 붙입니다.
2. 착지 이벤트에서 덩어리를 제거하고 파편 이미터를 버스트합니다. 메인 덩어리는 16개, 작은 덩어리는 7개입니다. 파편은 수평 160~560, 위쪽 500~1100px/s로 날리고, 바닥에서 반발계수 0.32로 한 번 튕긴 뒤 정지합니다. 정지하고 0.6초 뒤 0.5초 동안 사라집니다.
3. 낙하 중에는 작은 부스러기(11~15번)를 조금씩 흘립니다.
4. 앞발 짓누르기는 착지 프레임에 파편 14개를 버스트합니다. 예비 동작 1턴차에는 바닥에서 조약돌이 튀고, 2턴차에는 조약돌이 떨어집니다. 두 단계 모두 같은 아틀라스의 작은 파편을 씁니다.

## 바닥 균열
곡선 대신 **꺾인 직선 위주의 파괴 균열**로 다시 만들었습니다. 중심에서 방사형으로 갈라지며 2~4번 날카롭게 꺾이고, 꺾인 지점에서 곁가지가 뻗습니다. 동심원 모양으로 이어지는 거미줄 균열, 깨진 가장자리의 밝은 턱, 중심 크레이터도 들어갑니다.
1턴차에는 균열이 반쯤 열린 채 미세하게 떨리고, 2턴차에는 완전히 열려 틈에서 빛이 새어 나옵니다. 본 타격에서는 크레이터와 함께 바깥으로 빠르게 퍼집니다. 엔진에서는 Dust 시트의 마지막 프레임을 데칼로 잠시 남겨 두면 좋습니다.

## 공격별 재생 위치·타이밍
| 공격 | 시트 | 위치 / 타이밍 |
|---|---|---|
| 앞발 짓누르기 | `Stomp_Telegraph` (루프) → `Stomp_Impact_Glow` + `_Dust` + 파편 버스트 | 파티 진영 바닥 중앙에 재생합니다. 착지 시 화면 흔들림은 14px입니다. |
| 뿌리 후려치기 | `RootLash_Swing` + `_Leaves`, `ParryCue`, `RootLash_Hit` | 피벗은 보스 발밑 앞(프레임 상단 중앙)입니다. 뿌리가 오른쪽에서 파티 앞(카메라 쪽)을 지나 왼쪽으로 원근 호를 그립니다. ParryCue는 Swing과 동시에 시작하고, Swing 4프레임째 뿌리 끝 위치에 둡니다. Hit은 Swing 5·6·7프레임째에 오른쪽 캐릭터부터 순서대로 재생합니다. |
| 옹이 잔광 (패링 불가) | `KnotGlow_Charge` (루프) → `KnotGlow_Push` | Charge와 Push 모두 보스 앞쪽 옹이에 붙입니다. 압력파가 카메라 쪽으로 다가오며 커지고 두꺼워집니다. 이 공격만 연두빛을 써서 물리 공격과 구분합니다. |
| 언덕 무너뜨리기 | `Telegraph1` → `Telegraph2` → `HillCollapse_Impact_Glow` + `_Dust` + 잔해 파티클 | 위 레시피를 참고하세요. 화면 흔들림은 1턴차 2px, 2턴차 4px, 착지 22px입니다. 경고 문구는 UI로 띄웁니다. |

플립북 시트마다 `.json`에 프레임 구성(열×행), fps, 피벗, `screen_scale_1080p`가 들어 있습니다.
`screen_scale_1080p`는 1080p 화면에서 텍스처 1px이 차지하는 화면 px입니다.

## UE5 설정 요약
- 플립북은 `Sub Image Size` = (cols, rows), SubUV Linear, Lifetime = frames / fps, Pivot Offset = `pivot_uv`, Face Camera Plane으로 설정합니다.
- 포스트 프로세스는 Bloom 0.8~1.2, Threshold 0.8~1.0을 권장합니다.

## 다시 만들기
`src/`에서 `python build.py out/sheets`, `python boss_debris.py out/sheets/T_Boss2_DebrisAtlas.png`, `python scene.py out/preview` 순서로 실행합니다.
