## 8th-Team2-Final-Project Naia Unbound
> 나이아와 함께 성장하며 모험과 전투를 즐기는 턴제 MMORPG

Naia Unbound는 HD-2D 그래픽을 기반으로 나이아(정령)과의 교감, 캐릭터 성장, 전략적인 턴제 전투를 결합한 MMORPG입니다.

### 코어 판타지
* HD-2D 그래픽을 활용한 도트 그래픽의 감성과 3D 배경이 결합된 시각적 경험을 제공
* 나이아(정령)를 파트너로 맞이하고, 직업과 장비를 갖추어 자신만의 전투 스타일을 만드는 전략적 재미
* 최대 4인까지 팀을 만들어 보스 레이드 같은 협동 콘텐츠를 제공
